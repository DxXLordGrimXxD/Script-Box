# Script-Box- Kurz gesagt

TA Info BOX verbindet drei Werkzeuge in einem Userscript:

1. Forgotten-Analyse
Defensivaufstellung, HP, Einheiten-Level, Gebäude, Bedrohung und zusätzliche Hinweise.

2. Zielmarkierung
✓ / ? / ✕ direkt auf der Regionskarte, gespeichert und automatisch bereinigt, wenn ein markiertes Ziel fällt.

3. Tunnel-Übersicht
Tunnel, Offense-Anforderung, Einflussreichweite, Besitzer und Spieler in der Umgebung inklusive Kartenringen.
